# Лицензии и attribution для generated data

`LICENSE` в корне относится только к собственному коду и документации `ru-routing-lists`. Generated datasets наследуют условия конкретного upstream source и не переопределяются MIT-лицензией этого репозитория.

- pinned revision: `5d939545c84e2a534f8e85ba6ffb2b51fa18fb76`;
- pinned Git blob: `b2fb3fc8be62619f32f746cdda5bb32e18175324`;
- source URL: <https://github.com/v2fly/domain-list-community>;

Artifact является нормализованным/отсортированным представлением соответствующего source file и распространяется на условиях MIT с сохранением attribution upstream.

## Правило fail-closed

Новый source может участвовать в публикуемом artifact только если `sources.json` явно содержит `redistribution.allowed: true` и проверенную лицензию. Источники с `false` или `unknown` разрешены только как reference/oracle и не должны попадать в generated bytes.
